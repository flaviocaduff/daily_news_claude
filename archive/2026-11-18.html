TLDR InfoSec

Java4Shell: Critical OpenJDK Base64 Decoder Flaw Enables RCE

  • Calif disclosed Java4Shell (CVE-2026-114938), a memory-corruption bug in OpenJDK's Base64 decoder, rated 9.2/10 (critical) under CVSS 4.0.
  • An unauthenticated remote attacker can overwrite heap memory, leak data Heartbleed-style, or reach remote code execution.
  • Trigger: 64 'A' characters followed by '=' (128 'A's in OpenJDK 17). The flaw sits in AVX-512 assembly used for fast decoding.
  • Calif reports RCE in default configs: pre-auth in Keycloak, Jira, Confluence, Jenkins; post-auth in Kafka, Elasticsearch, Solr and others.
  • Separately, samczsun shared a client-side exploit: Java programs connecting over TLS to a malicious server can be compromised.
  • Calif says AI helped find and exploit it: about one hour to discover, two more for a working exploit, under $200 in tokens. The text mentions no patch.
