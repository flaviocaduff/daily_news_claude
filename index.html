Empa builds AI chat tool for complex alloy design

  • Empa researchers in Thun built OptiMat Chat, which lets scientists run materials simulations through plain-language text chat, calculated on their own computer.
  • Focus is high-entropy alloys, which mix four or more metals in near-equal proportions. Their design space is too large for traditional trial-and-error experiments.
  • The first agent, OptiMat Alloys, selects domain tools, runs best-practice workflows, and outputs publication-style figures and tables for expert review.
  • Results are stored in a database for traceability and reuse. Outputs come from validated tools rather than the language model alone, to reduce hallucinations.
  • Researchers warn the outputs are starting points for expert interpretation, not publishable results. Planned agents cover ceramics, metal oxides and amorphous materials.
  • The work is described in npj Computational Materials (2026).

TLDR InfoSec

httpx Vulnerable to RCE via Oj Object-Mode JSON Deserialization

  • httpx 1.9.0 (Ruby) parses JSON responses with Oj in default :object mode when oj is loaded and multi_json is absent, enabling object instantiation.
  • With ActiveSupport loaded, as in Rails, a gadget chain turns a fetched response body into remote code execution as the app user.
  • Exploitable by anyone who can influence a URL the application fetches; no user interaction required.
  • Not affected: apps keeping multi_json, pinning a safe Oj default, or passing an explicit safe mode at the call site.
  • Fixed in httpx 1.9.1 (strict Oj mode). Workarounds: response.json(mode: :strict) or Oj.default_options set to strict.

TLDR IT

Microsoft Defense Guide Makes Layered Prompt Injection Controls an Enterprise Baseline

  • Microsoft's security guidance warns that copilots and AI agents are exposed to indirect prompt injection through untrusted emails, documents, websites and plugins.
  • Core problem: AI cannot reliably separate user instructions from embedded third-party content, so input validation alone falls short.
  • Recommends layered defenses: prompt shields, spotlighting, plan drift detection, critic agents, tool-chain analysis and information flow control.
  • Also least privilege, short-lived privileges and human verification of risky actions as the last line of defense.
  • Trade-offs include added complexity, latency, false positives and ongoing investment; the guide assumes injection is inevitable and designs for containment.
