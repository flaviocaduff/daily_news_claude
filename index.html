TLDR InfoSec

httpx Ruby Gem RCE via Oj JSON Deserialization

  • httpx 1.9.0 allows remote code execution when the oj gem is loaded without multi_json and the response is parsed with Oj's default object mode.
  • Attacker controlling a fetched URL can reach RCE via ActiveSupport gadget chain; Rails apps are affected; no user interaction needed.
  • Staging payload via ordinary multipart POST, then JSON gadget document triggers Kernel.load on the tempfile.
  • Apps keeping multi_json, pinning Oj.default_options, or passing safe mode are not affected.
  • Fix: upgrade to httpx 1.9.1 (commit eeb785d), which uses strict mode; interim workaround is response.json(mode: :strict).

TLDR IT

Microsoft Defense Guide Makes Layered Prompt Injection Controls an Enterprise Baseline

  • Microsoft's defense guide treats layered controls against indirect prompt injection as a baseline for enterprise copilots and AI agents.
  • The risk: assistants can't reliably tell untrusted external content, like emails or web pages, from legitimate commands, enabling unauthorized actions and data breaches.
  • Recommended layers include prompt shields, spotlighting, plan drift detection, critic agents, tool-chain analysis, and information flow control.
  • Least-privilege, short-lived permissions and human approval for risky actions form the final lines of defense.
  • Trade-offs: more complexity, latency, false positives and ongoing cost; no universal fix, so each system needs tailored evaluation.
  • Guidance assumes injection is inevitable and prioritizes containment and recovery, with threat modeling built in from the design phase.
