TLDR InfoSec

Microsoft agent-framework PyPI Versions 1.26.1–1.26.2 Compromised

Two malicious versions of Microsoft's agent-framework package were published on PyPI, the public library site for Python code. They steal developer and cloud login secrets.

  • The malicious versions are 1.26.1 and 1.26.2. The OpenSourceMalware team found them.
  • They were published through Microsoft's real PyPI account, so name checks and lock files would not have caught them.
  • A startup file (.pth) runs the stealer whenever Python starts. The package does not need to be imported.
  • The stealer searches environment variables, credential files and other running processes for passwords and tokens. It reads up to 80 files and 300 process environments.
  • It also requests new GitHub Actions, Azure DevOps and Azure identity tokens. It sends all stolen data to a webhook.site address.
  • PyPI has quarantined (blocked) the Microsoft publisher. The attacker probably still has access, since 1.26.2 was published after the block.
  • Treat any install of either version as a credential breach, even after a fix. Download counts do not show how many people were hit.
  • The source text cuts off in the section on token theft.

Why it matters: Any developer or build system that installed these versions should replace its passwords and tokens.

Neutron imaging confirms new 156-million-year-old reptile species from Wyoming

Swiss scientists identified a 156-million-year-old fossil from Wyoming as a new reptile species. They used neutron imaging at the Paul Scherrer Institute (PSI) and University of Zurich.

  • The Aathal Dinosaur Museum in canton Zurich team found the fossil in August 2022, in Wyoming's Meilyn Quarry.
  • Neutrons (tiny particles that can see inside materials) show hydrogen well. Bone contains hydrogen, so bones stand out from the surrounding sandstone.
  • PSI materials scientist Pavel Trtik and University of Zurich palaeontologist Torsten Scheyer led the international research team.
  • X-ray scans from PSI, Empa in Dübendorf and the University of Zurich were combined with the neutron images.
  • Researchers sifted tens of thousands of cross-section images. They found pelvic bones, part of a hind leg and a tiny skull.
  • The reptile was about 45 centimetres long, with two dragon-like horns on the back of its head.
  • The braincase (the skull's protective bone case) is almost fully preserved and under 2 centimetres wide. It is the key clue to the animal's relations.
  • The animal belongs to the choristoderes, a long-extinct reptile group whose place on the family tree was unclear. Its inner-ear bones resemble those of living reptiles, suggesting closer ties to them.

Why it matters: It shows how combined imaging tools can answer questions that stumped experts.

  • Wiz used its own AI code-scanning tool to find both flaws. It says AI makes long-hidden bugs easier to find and exploit.
  • Users should update to the latest NGINX release. If an update is not possible, they can temporarily turn off HTTP/2.

Why it matters: If you run NGINX, check your version, update it, or turn off HTTP/2 now.

The Solana Foundation, the non-profit behind the Solana blockchain, now holds a majority stake in CoinGecko, a crypto data platform.

  • CoinGecko is a crypto price and markets platform based in Malaysia. The post calls it the number one crypto data platform.
  • The post says CoinGecko reaches tens of millions of users monthly on web and mobile.
  • It serves 180,000 developers and businesses with pricing data, according to the post.
  • The post credits CoinGecko's founders, @bobbyong and @tmlee, with 12 years of building the company.
  • Planned work includes on-platform trading and DeFi (decentralized finance, trading without banks) built on Solana.
  • Other plans include wider coverage of equities (stocks) and RWAs (real-world assets, such as tokenized assets).
  • The source does not give the price, deal terms, or the post's author.
  • The source text also includes unrelated posts about retail stores and startup decks. These are left out.

Why it matters: A major crypto price-data site now sits under a blockchain foundation's control, with trading plans attached.

Plaid launches Agent Detection to identify AI-driven financial activity

Plaid, a US company that links apps to bank accounts, launched Agent Detection. The tool tells banks and fintechs (financial tech firms) whether a visitor is a human or an AI agent.

  • AI agents are software that can act for a person, such as browsing sites to finish tasks. Grok Bot, Meta Muse, OpenAI dots and Claude Duet reached consumers within weeks of each other.
  • Agents now appear on login pages, sign-up flows and account-linking steps, which makes it harder for companies to know who is acting.
  • Agent Detection checks thousands of signals, including device, behavior, automation patterns and network activity, to spot agents and name the AI provider behind them.
  • Example: if a customer's agent asks to pay a bill, the bank can see the agent and handle the payment accordingly.
  • Plaid says that in side-by-side tests on live traffic, its tool found 2.3 times more agent sessions than competitors. It reports no rise in false positives (real humans wrongly flagged as agents). These are Plaid's own results.
  • Companies add it through a lightweight SDK (a ready-made software kit) that does not disrupt the user experience. Customers already using Plaid may get it through their existing setup.
  • Plaid already links many AI assistants, including ChatGPT, Claude, Perplexity, Grok, Meta Muse and Google Gemini, to bank data. Users approve access without sharing bank passwords, and access is read-only.
  • Plaid plans a secure way for users to approve specific agent actions, and is expanding its Trust Index (a risk-scoring tool) to cover agent activity. Neither is described as available yet.

Why it matters: Banks and fintechs can now see when an AI agent, not a person, is using their services. This matters as agents start to move money.
